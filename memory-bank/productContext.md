## Project Goal

* Create UI components for the Lantau project.

## Key Features

* All UI components are built with Svelte 5.
* All UI components should be coded in the `src/UI` folder.
* All UI components should have their display and preview in Storybook. The Storybook files should be located in the `src/stories` folder.

## Overall Architecture

* The project is a Svelte-based component library.
* Components are located in `src/UI`.
* Storybook is used for component development and demonstration, with stories in `src/stories`.
